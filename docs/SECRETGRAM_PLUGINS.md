# Плагины SecretGram для iOS

Раздел: **Настройки → SecretGram → Плагины**. Интерфейс русский и английский, по языку приложения.

Реализованы выбор файла через «Файлы», распознавание Python `.plugin`, ZIP-контейнера `.plugin` и заголовка DEX, сохранение, просмотр названия/версии/формата и удаление. Записи изолированы по аккаунту. Лимиты: 10 МБ на файл, 50 файлов и 100 МБ на аккаунт. Повторный импорт создаёт отдельную запись. Все операции с диском выполняются вне главного потока; ошибки показываются пользователю.

**Запуск сторонних плагинов не реализован.** Импорт не означает установку работающего плагина. Даже распознанный файл всегда помечен «Не выполняется на iOS». Заголовок файла используется только для классификации, не для проверки корректности исполняемого кода. Архивы не распаковываются, Python не исполняется, DEX не загружается.

По [официальной документации exteraGram](https://plugins.exteragram.app/docs), движок использует Python 3.11, Chaquopy и Android/Java-хуки. Swift-клиент не имеет соответствующих Android-классов. Поэтому добавление одного Python-интерпретатора не обеспечит совместимость. Для выполнения необходим перенос конкретных функций на Swift и отдельный iOS API плагинов; для `.dex` нужен Android Runtime и совместимый Android API. Они в этот проект не встроены.

Произвольный плагин AyuGram не объявляется совместимым лишь по расширению. Для следующего этапа нужны конкретные плагины и список функций, которые требуется перенести.

Проверки на Mac: `sh scripts/test-secretgram-plugins.sh`. Затем собрать приложение и проверить импорт Python/DEX/ZIP, отмену выбора, ошибочный и слишком большой файл, повторный импорт, перезапуск, смену аккаунта и удаление. Swift-тесты и сборка iOS в Windows не запускались.
