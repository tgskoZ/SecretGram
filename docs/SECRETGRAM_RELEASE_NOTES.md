SecretGram для iOS — экспериментальная сборка на основе предоставленных исходников Jerkgram / Telegram 12.9.2.

- Название SecretGram и иконка с самолётом и замком.
- Раздел «Плагины»: импорт `.plugin` и `.dex`, распознавание формата, хранение и удаление. **Выполнение Android-плагинов не поддерживается.**
- Удалены аналитика и ссылки на каналы исходного приложения.

**SecretGram.ipa предназначен для самостоятельной подписи** через AltStore, SideStore, ESign и аналогичные инструменты. Без подписи IPA не устанавливается. Работа push-уведомлений и расширений зависит от подписи и доступных entitlement/App Groups. Проверка установки на физическом iPhone не выполнялась.

CI проверяет Swift-тесты импортера и формат IPA (iPhoneOS / arm64), затем публикует файл и SHA-256. Это не App Store-релиз и не подтверждение работы всех функций на устройстве.

По умолчанию используются публичные примерные параметры Telegram API из исходного проекта. Для собственной API-регистрации задайте GitHub Secrets `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` и пересоберите.
