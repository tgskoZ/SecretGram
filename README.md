# SecretGram for iOS

Native iOS Telegram client derived from the supplied Jerkgram snapshot. This is a modified source tree, **not a verified IPA release**.

- SecretGram name, first-party modules, settings, permission descriptions and icon assets.
- Supplied lock/plane artwork used for SecretGram icons and previews.
- Experimental `.plugin` / `.dex` import, inspection, account-specific storage and removal. **Android plugins do not execute in this build.**
- Upstream analytics and community channel integration removed.

See [build instructions (Russian)](docs/SECRETGRAM_BUILD.md) and [plugin scope](docs/SECRETGRAM_PLUGINS.md). A Mac with Xcode is required. iOS compilation and device tests have not run in the Windows workspace.

Inherited release/design documents describe upstream history, not tested SecretGram releases. Upstream release hashes do not identify this modified tree.
